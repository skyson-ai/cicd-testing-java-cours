## Overview

Repository tracking exercises from the CICD course ([EazyTraining](https://eazytraining.fr/cours/cicd-pour-developpeurs-debutez-avec-le-devops-quand-on-est-developpeur/)). Covers CI/CD pipelines for Java applications.

## Topics Covered

- Unit testing with JUnit
- GitHub Actions CI pipelines
- Docker containerization
- Maven build automation
- Deployment strategies

## Getting Started

```bash
git clone https://github.com/skyson-ai/cicd-testing-java-cours.git
cd cicd-testing-java-cours
mvn clean install
```
